- Step 1 (theme tokens + fonts): `theme/` has colours (DESIGN.md 2.1), typography (2.2, Geist + Geist Mono variable fonts in `res/font`), dimensions (2.4).
- Step 2 (started): `HomeActivity` (HOME intent, opaque window), 7-page `HorizontalPager`, `PageDots`, clock block on screen 1. Long-press the clock to flip light/dark (temporary, until the mode switch tiles exist). Other pages are placeholders.
- Design update: typography rescaled to very small type (DESIGN.md 2.2: clock 56 sp etc.) and the page dots replaced by the page indicator (DESIGN.md 2.6). `GlyphType` now has `homeClock`, `worldClock`, `bigStat`, `mediumStat`, `monoStat`, `screenTitle`, `rowPrimary`, `rowSecondary`, `label`, `meta`, `smallest`; `PageIndicator` follows the swipe live, shows number/total/name only while swiping (hides 1.1 s after), and the pager settles in 480 ms with the spec easing.
- Dock (Phone, Messages, Camera, All apps; the app drawer button is a TODO until step 5) and the Orbit and dots home background (DESIGN.md 5A: one clock, paused on ON_STOP, per-page orbit positions interpolated with the swipe, 60 dp parallax and 8° rotation per page). Page indicator now sits 22 dp above the dock.
- Design update: the Today search bar has three buttons (voice, Lens, incognito). Not built yet; it belongs to step 4 (sample-data screens).
- Design update: the light/dark mode switch icons have transparent backgrounds; active = full ink, inactive = ink.dim. Not built yet (still the temporary long-press on the clock).
- Step 3 (page transition, DESIGN.md 4): `PageTransition.kt`. `glyphPage` gives the page fade (1 − 0.12·|offset|) and the 2 dp·|offset| `RenderEffect` blur; `glyphCard(index)` gives the card cascade (−offset·(index+1)·70 dp while dragging, then on release each card settles with a 55 ms·index stagger over 520 ms); the background parallax and ring rotation were already driven by the pager position. Cards on Today and the placeholders use `glyphCard(0)`. Not done: rubber-band at the first and last page (drag × 0.3); the pager's default stretch overscroll is used for now.
- Lotus assets: `lotus_light.png` (black ink, transparent) and `lotus_dark.png` (white ink, transparent) in `res/drawable-nodpi`, 1024 × 1536, generated from the two source images in `assets/` (light: flattened on white, darkness → alpha, which also removed the halo from the original cutout; dark: brightness → alpha). Used in step 6.
- Step 4 (started): screen 1 Today with sample data (`screens/TodayScreen.kt`, `screens/today/*`, `data/TodaySample.kt`): clock block, mode switch (moon/sun, transparent backgrounds, active = ink, inactive = ink.dim), search bar with voice / Lens / incognito, weather + battery + screen time row, next event card. The light/dark mode is now stored in DataStore (`data/SettingsRepository.kt`, default dark); the temporary long-press toggle is gone. New icons in `GlyphIcons`: Moon, Sun, Search, Mic, Lens, Incognito. Search intents are in `launcher/Launch.kt`; Lens (`google://lens`) and incognito (Chrome extra) are unverified until tested on the 12R. Screens 2-7 are still placeholders.
- First on-device test (OnePlus 12R, installed with `adb install -r`; launched with `am start`, not yet set as default Home). Verified by screenshot: fonts, Orbit and dots background, dock, page indicator (label shows while swiping, hides after 1.1 s), mid-swipe blur/fade/background parallax, light and dark mode switch (persisted). Fixes from the test: system bar icons now follow Glyph's mode (they were black on black in dark mode); `HomeActivity` locked to portrait; Lens now launches the standalone Lens app (`com.google.ar.lens`); incognito uses Chrome's own `org.chromium.chrome.browser.incognito.OPEN_PRIVATE_TAB` action (the old extra opened a normal tab); voice opens the Google/Gemini voice UI. Open points: transparent cards keep their 16 dp padding, so Weather and the Battery/Screen time text sit indented from the 20 dp margin that the clock, search and event rows use (decision pending); rubber-band overscroll still missing.
- Usable-as-default batch (verified on the 12R): transparent cards have no inner padding; dock is Phone + Camera only; Life page removed (6 pages; orbit table and indicator updated); app drawer by swiping up from any page (`drawer/`: `DrawerState`, `AppDrawer`, `AllAppsView`, `CategoriesView`, `AppCell`, `CustomIcons`; `data/`: `AppRepository` via `LauncherApps` with real icons and a package-change callback, `AppCategories`, launch counts in DataStore for suggested apps). - Step 6 (live wallpaper "Bloom and wind", DESIGN.md 5B): `wallpaper/BloomRenderer.kt` (still layers drawn once into a bitmap: dot grid, folds, vertical line + dots, dotted arc, wind thread, lotus, red dot; moving layers: 12 rain lines and 28 dust motes, seeded once) and `wallpaper/BloomWallpaperService.kt` (Choreographer capped at 30 fps, stops when not visible, light/dark from the shared DataStore flag, `onComputeColors()` neutral greys). The wind-thread curve is a guess (not in the spec). Recents (OnePlus fallback `RecentsActivity`) draws on top of the system wallpaper, so applying this to Home gives recents a Glyph background; not yet confirmed on the device. - Wallpaper: lotus removed (everything else unchanged); wallpaper thumbnail attribute dropped and the description shortened to "Bloom and wind". The lotus drawables stay in `res/drawable-nodpi` but are not used.
- Fixed the drawer swipe from Today: the page now scrolls vertically, so upward drags it cannot use are handed to the drawer (nested scroll). Each reports a `SourceState`; cards show a dash plus a tap-to-allow hint instead of fake values. `TodaySample` is gone. First run prompts for location, calendar and steps in a chain. Verified on the 12R: weather, hourly, AQI and sunrise/sunset real; calendar returns none upcoming; steps read 0 (no app writes steps to Health Connect yet); screen time waits for Usage access.

Volume bar is live (tap/drag sets media volume, follows keys, re-reads when outputs change). Tapping the player opens YouTube Music. - Swipe down on home opens the system notification shade: `HomeScreen` adds up downward pulls (page overscroll via the nested-scroll connection, or the root drag) with `ShadePull`, and on release over 72 dp calls `HomeActivity.openNotificationShade()`, which uses `StatusBarManager.expandNotificationsPanel` by reflection (permission `EXPAND_STATUS_BAR`). Not tested on the phone yet; if the OxygenOS build blocks the reflection call, the fallback is an accessibility service (`GLOBAL_ACTION_NOTIFICATIONS`).
- Swipe down is now two-stage (replaces the plain "open the shade" above): a pull of 56-300 dp reveals a Glyph shortcuts popup (`shortcuts/ShortcutsPopup.kt`, `ShortcutsPopupState.kt`; follows the finger, latches open on release, scrim closes it), a pull of 300 dp or more goes on to the system shade. `ShadePull` in `HomeScreen` now reports the running distance and the final distance instead of deciding. Seven buttons: Hotspot QR, Hotspot (opens `com.android.settings.TetherSettings`, falling back to the wireless settings list), Flashlight (`shortcuts/Flashlight.kt`, `setTorchMode`, state from a `TorchCallback`), Glyph mode, Focus (`FocusTimer`), Homelab (`tiles/HomelabCheck.kt`, shared with the tile) and GPay scan. Not checked: Glyph mode button (would change the saved Auto setting), Hotspot settings page, Homelab (no address), QR code itself (needs a hotspot name and password). The five "Add tile?" system prompts were never answered, so the tiles are not in the Control Centre yet (flag reset with the debug `tiles-reset` broadcast; the tiles can also be added by hand from the Control Centre's edit screen).
